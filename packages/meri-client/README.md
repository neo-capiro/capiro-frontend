# Meri browser client

This package owns browser subscription guarding, immutable conversation projection and the React facade. Trusted source access, authentication, authorization, publication fences and durable state remain in the separate Meri backend.

Import `createMeriChat`, `MeriGuardedTransport` or `guardUiChunk` from the root; projection and safe error rendering from `/projection`; `useMeriChat` and `detachMeriView` from `/react`. The React entry is explicitly a client component. Private source imports are unsupported. Canonical wire types/validators are supplied by public @capiro/meri-contracts0.1.3, preserving the original0.1.0 event wire contract; the separate backend stream adapter owns SDK transport protocol names. There is no mirrored event DTO authority here.

The caller supplies an explicit approved `api` endpoint, authenticated fetch and a validator that returns a canonical UIEvent or throws. The migration intentionally removes the qualification's guessed `/api/chat` default; missing/blank endpoints fail before Chat allocation or fetch. Offline fixtures supply that historical mock route explicitly. Offline qualification injects the canonical Node validator; a browser integration must use the public browser validator at this same boundary. A browser view is an intended subscription scope, never proof of authorization. The server must establish trusted context and recheck current authority. Every event is validated before synchronous projection admission. Immutable conflict or cross-view binding aborts the subscription before the offending event reaches observers. Reconnect uses the accepted contiguous cursor, never a caller-supplied sequence.

`detachMeriView` disposes only the subscription. It does not cancel a run. Stream finish, HTTP204 and hook readiness do not prove run completion; only authoritative run.status does. Browser durable storage, live session binding, revocation and hydrated behavior remain later gates.

Develop from the repository root with its sole workspace lock: `npm ci --ignore-scripts --no-audit --fund=false --update-notifier=false`, then `npm run build --workspace @capiro/meri-client`. Earlier standalone locks remain immutable qualification baseline data. Compile actual JS/declarations before packing; installed packages must not rely on Node stripping TypeScript. The frontend qualification package preserves the19 original composed behavior cases and adds two endpoint/browser-validator controls using public exports. The web fixture is still disconnected and does not instantiate this client against a guessed endpoint.

`createMeriConversation` from `/conversation` composes the separate public0.1.3 receiving contract with the existing guard and actual SDK Chat. Supply the canonical opaque-session credential, server-selected context, expiry, lifetime signal and current-selection callback. Browser selection never authorizes a request. This handle owns admitted views and cursors internally; it accepts no caller-created receipt or numeric reconnect cursor. Use `submit` once, `retrySubmit` only for the same unknown intent, `history` for an explicit admitted page/checkpoint, `openChat().chat` for observation, and `cancel` only for an explicit durable cancellation request. Subscribe to `getSnapshot` for loading/unavailable/disposed and retained write uncertainty. The observation's additive `prompt` is the admitted request text for the bound run: the stored history request, or the exact submitted input; it is `null` only when neither was admitted. A cancel receipt may report completed or failed; observation finish never completes a run.

Conversation streams retain the upstream SSE parser behind strict original UTF-8, an8MiB segment budget and a30second observation deadline. JSON responses are limited by the public2MiB cap. The public receiver owns contiguous sequence, exact binding/scopes and10,000 retained identities; an explicit fresh history checkpoint recovers a full cursor. Display retains at most1,000 streamed events and reports omitted prefixes/remaining pages. Only the pinned producer's plain lifecycle frames and transient governed event frames are admitted. Parser diagnostics and unadmitted metadata/text cannot become SDK display content. Disposing clears owned content/credential references and stops observation without issuing durable cancel; a failed retry preserves an earlier uncertain write.

The normal `npm run test:transport` command includes the original21 cases and additive receiving controls. Exact backend interoperability is a separate offline gate: set `MERI_CONVERSATION_QUALIFICATION_SOURCE` to a byte-verified extraction of Meri93845774d352fc9a0ad12cc7bc8bd3d4612a322c and run `npm run test:cross-repository --workspace @capiro/qualification-transport`. That test imports the backend's synthetic identity/store/dispatcher fixture only; production imports remain public packages. Ordinary Meri host activation, a navigation-persistent write journal and an authenticated deployed streaming proxy remain open, as do native database/provider/worker and live authorization gates.
