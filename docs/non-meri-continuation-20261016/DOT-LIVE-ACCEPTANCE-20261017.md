# Dot-owned live first-chat acceptance

**Owner:** dot, after Fable returns the deployed frontend, Core and Meri source/image digests, the reviewed preview configuration, and healthy service evidence. This is step 3 of Neo's 17 October handoff. Fable owns image qualification and service activation/integration (steps 1–2). No live user-authenticated check was run while preparing this checklist.

At handoff, [Core's held service](https://github.com/neo-capiro/capiro-backend/blob/635486fd21f0fb0f6893241f47dbfef7d343d849/docs/core-first-chat-fable-shipping-handoff-20261017.md) is 0/0/0 behind a retained 404 guard on `first-chat-preview.app-dev.capiro.ai`; its receipt migration and private startup passed, but public authenticated HTTP has not. Fable must first provide the separately approved serving Core target and Meri admission proof. Core's native identity/context paths are `POST /api/clio/application-authority/identity` and `/context`; the frontend bootstrap target is `https://first-chat-preview.app-dev.capiro.ai/api` through its server gateway, never a direct browser bearer call to the Core host.

Fable must also supply a qualified **separate selected-client read target**. The current Core first-chat host routes only named POSTs, and its guard returns 404 for frontend upstream GET `/api/me`, `/api/clients` and `/api/clients/<id>`. Dot's step 2 cannot pass until the narrow `CAPIRO_PREVIEW_READ_API_BASE_URL` route is reviewed and verified with native bearer and actual client scope; the ordinary production-bound Core URL is not a fallback.

Use the designated preview Test Clerk application and a permitted test tenant/client. Capture a sanitized case ID, UTC time, route, status, request correlation ID, selected-client match or mismatch, and result for each step. Keep bearer tokens, cookies, raw prompts, model output, secret references' payloads, private logs, and real tenant/actor/client IDs out of Git. An authenticated browser network trace and backend admission record may be retained in the approved private evidence store, with identifiers redacted in the shipping decision.
