Size findings remain visible review signals. The records in `docs/architecture-size-reviews.json` apply only to the final inspected source hashes; no limit or inherited baseline is relaxed. AST/dependency inspection is separate from full semantic typing.

The independent `contact_mail_date_fix` review inspected the Commitment, overview, Strategy navigation, Work projection and four-read evidence catalog. It found the Library Actions-column Open client-argument omission; root corrected it and the reviewer inspected the correction. The review accepted source cohesion after that correction, without claiming runtime tests. The independent `engagement_continuation_review` inspected Government/location composition, attribution, failure handling and District selection. Its request to separate location/representation presentation and the four evidence cards was implemented before final source binding.
