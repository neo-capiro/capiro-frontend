Bootstrap uses optional equality hints; it never manufactures a run, client identity or authority. A successful receipt creates an in-memory transport/port; the adapter retains context/expiry without the bearer, and the transport clears its current credential when the host lifetime aborts. The host schedules idle expiry at the receipt deadline, aborts pending work and removes the rendered port on expiry/access loss/disposal. Captured lifetime equality prevents late bootstrap success from replacing a newer host. Reconnect is explicit, and a same-context journal can keep a previous unresolved operation fenced.
