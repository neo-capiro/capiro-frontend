Findings communicated directly to the implementation owner:

1. **MA-01, P2 — query uncertainty was omitted from the journal.** Original `workflow-adapter.ts:100–133` exempted `query` from pending/unresolved retention, allowing a new adapter over the same journal to repeat an uncertain or acknowledged-but-withheld lookup. PR47 `action-application/index.mjs` blob `a102d9242292ed818f0c27ab55a392947379dcde` sets `queryStarted`/`queryStored`; `task-lookup/delivery.mjs` blob `ed95692d75a0c4d028e6afaa5106d31d5d1cb6f6` performs claim, dispatching and retained-result metadata transitions. `action-application/http.mjs` blob `cf933d08ee56e4c07a883b48097e50d45e5ad077` preserves that state through later read-local refusal. This is a lookup metadata/retry defect, not demonstrated duplicate task creation. Root captured its original source and red controls, then removed all four-route journal exemptions. A lost/unvalidated query acknowledgment must also remain `unknown`; native `READ_UNAVAILABLE` is reserved for an admitted error response.

2. **MA-02, P2 — acquired response bodies escaped cleanup on early rejection.** Original `bounded-json.ts:7–20` threw for pre-abort, incorrect media type or oversized declared length before entering the reader cleanup `finally`; a fetch result arriving after the raced deadline followed the same path. The acquired stream could remain live. Root moved the whole receiving operation inside cleanup and cancels the unacquired-reader body as well. The independent transport/session lane captured four real failing controls before this correction. Stream cleanup cannot establish physical rollback of a native request.

3. **MA-03, P2 — session parser differed from PR47 issuance grammar.** Original `session-receipt.ts:6–11,25–29` used RFC UUID parsing rather than PR47's lowercase simple hex pattern, omitted the 256-character tenant/actor caps and semantic 4096-byte receipt bound, and allowed negative integer clocks. Native owner blob `9ec0c2970949f1c66eb790aa53c2170a00c8a581` supplies the exact grammar. This both refused some native-admitted identifiers and admitted impossible native wire values. Seven grammar controls independently failed before correction. Root now applies that exact pattern/caps and nonnegative safe clock; the network bootstrap separately owns the raw streamed body bound. The native session-owner TTL ceiling is five minutes, while `assertActionSessionReceipt` itself only requires future expiry. The browser also retains the issuance ceiling.

4. **MA-04, P2 — a receiver-valid query could describe a different request.** Original `correlation.ts:47–55` checked stable lineage and client, but not requested first-page intent. The adapter issues `{request:{limit:20}}`, yet accepted coherent echoed scope/selection with limit50 or a cursor page2, then labelled it a bounded first page. Native `task-lookup/binding.mjs` blob `5337c05f73a7535b0564da15f6f819b56409fa37` normalizes the actual request and asserts its output; the public browser receiver does not perform this cross-request check. The unchanged independent pure probe confirms both synthetic negative responses pass the public receiver and original correlation, while the original first page passes. Exact native defaults are actionItemId/status null, sort deadline, page1, limit20, cursorApplied false. A cursor selection's page is null, not2; the separate native read scope may report page2. Root owns the correction and regression adoption.
