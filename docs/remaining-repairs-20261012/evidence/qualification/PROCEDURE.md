# Combined qualification procedure

Freeze all feature source and exact architecture reviews in one source commit before executing these gates. Do not commit documentation/evidence during the run: each gate records identical HEAD/root/application trees and a clean source diff before and after. Generated receipts/build/browser output are evidence, not source changes.

1. Confirm all owner browser/typecheck processes are stopped. Unlink only the root worktree borrowed node_modules symlink (after proving its exact target), then clean install with npm ci --ignore-scripts. Preserve borrowed PR14 dependencies and every other worktree.
2. Run npm run check on the frozen source. It includes public exports, all workspace TypeScript, root tests, exact architecture, transport, lint/format, Portfolio unit and Capiro unit checks. Record original warning totals and all inherited unreviewed findings.
3. Prepare the pinned Elements SSR tool into a new output directory with packages/qualification-elements/ssr-build.mjs and verified /tmp/capiro-elements-tool; retain complete receipt/output. Run check:elements with the exact receipt path and SHA and a separate fresh capture directory. The receipt build directory already exists and must never be reused as MERI_ELEMENTS_SSR_CAPTURE_ROOT.
4. Build the standalone host candidate using npm run build; record BUILD_ID. Run actual standalone test:production with Chromium /usr/bin/chromium and a new artifact directory. No credential/provider/environment changes or external service calls.
5. Run the entire Modules browser suite with one worker,60s,zero retries and the entire Portfolio suite with three workers,60s,zero retries (four already-declared slow cases remain180s). Sequential suite execution avoids resource/port contention; assertions/config/source are unchanged. Copy raw result JSON plus all canonical screenshot/trace output. External worker/timeout/output overrides are explicit command evidence.
6. Independently verify the final source/test/ledger mapping, gate outputs and evidence bytes using existing agents. Publish a separate evidence-only commit and draft PR based on frozen PR14. All337 native rows remain held; live auth/persistence/providers/full Figma/accessibility/deployed-image/shipping remain explicit limits.

Raw gate helper: run-gate.py. Use a fresh final-<sha> directory. Never replace prior failures or earlier source snapshots. Fix genuine source failures with a new source commit and requalify the affected evidence honestly; do not weaken gates.

7. The subsequently requested Docker shipping-defect verification additionally builds the exact frozen source with apps/web/Dockerfile and its pinned Linux base into a uniquely named local image, then runs the existing local container smoke. This is a second, explicit container production build; it is not a third AWS attempt or a deployment. Run the real Docker context red/green regression with the final script and retain all failed/setup attempts. Native Meri workspace interactions remain distinct from Portfolio browser coverage.
