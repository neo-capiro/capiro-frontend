## First non-Meri preview slice

**Current state:** a PR #97 image swap alone is not a real-API Portfolio or Modules preview. The checked-in [preview profile](../../../apps/web/deployment/portfolio/preview-config.mjs) fixes `CAPIRO_PREVIEW_READ_ONLY=true`, leaves its separate first-chat read opt-in false by default, points ordinary Core/Workspace/Intelligence origins at the preview hostname, and leaves Strategy and Onboard empty. Its [read route](../../../apps/web/src/shared/preview/read-route.server.ts) admits only GET `/me`, `/clients`, `/clients/:id` through the Portfolio proxy, or `me.read` and `clients.list` through the Modules proxy. Other ordinary requests return `503 PREVIEW_BACKEND_HELD` before dispatch. The documented Core preview target `https://first-chat-preview.app-dev.capiro.ai/api` was held at zero tasks and its retained host guard did not serve even those roster GETs; source marker `6542f5b089656b6d255465edd464d06c2a0b408f` is not serving proof.

The first bounded live read would be authenticated client identity and roster for the `/modules` scope selector and Portfolio client navigation. It requires a running Core GET target, correct Clerk issuer/key and tenant/member authority, and reviewed listener routing. **It is not a complete Portfolio screen:** `/portfolio?type=CLIENT` also starts GETs for account owners, owner options, Business Development prospects, and (for an authorized user with clients) portfolio alerts. The default Congressional Directory under `/modules/directory` starts `directory.contacts` and `directory.favorites`. For a useful read-only cross-feature test slice, the frontend owner must validate and explicitly allow those exact GET contracts against an independently qualified Core target, or scope the UI to honest unavailable states. Portfolio Add profile and Directory favorite writes currently remain visible; they need an explicit held/read-only presentation before describing that slice as usable. Quick Log, Files storage usage, Planner, Workspace, Intelligence, sends, and mutations are outside this first slice.
