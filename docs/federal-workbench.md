# Exact federal text review

The connected Word file workflow can import an exact official bill version cited in its current conversation, open a retained TXT source envelope, prepare one literal replace, insert or delete amendment, save immutable review revisions and export operative, consolidated or redline TXT. Loading an existing multi-operation review supports reviewing and exporting it; editing it requires the full authoring surface, which is not implemented here. Official imports are re-read against current Core authority at preparation/load/publication; other publisher metadata remains a retained claim. Legal currency, enactment, numbering and substantive-law checks remain visible and unresolved.

## Ownership and failure handling

`FederalWorkbench` owns transient form, pagination, review confirmation and verified download presentation. Any amendment edit clears the prepared review and confirmation. Its effect lifetime cancels obsolete work, including development StrictMode replay. It neither compiles amendments nor grants authority.

`FederalWorkbenchAccess` uses the published `@capiro/meri-contracts/federal-workbench` receiver and existing document library. The canonical runtime compiler and Core current authority remain remote. Publishing uses the existing document attempt journal shared with ordinary document writes. A changed revision or output cannot replace an uncertain original delivery; remount recovery reconstructs the exact intent and reuses its original delivery ID. The journal stores hashes, identity and disposition, not review/source content. Saving a revision binds its old saved version and old reviewed digest separately from the new digest.

`FederalSourceImporter` pages the existing scoped conversation-history reader for saved native bill citations. It submits the exact bill/version/revision/version-hash/text-hash selection; retained citation metadata is only a selector. The runtime re-reads full current official bytes and retains a canonical immutable envelope. Imports and exports share the same delivery transaction and journal. An unresolved import prevents switching to a different import or export; remount recovery requires selecting the original citation. Cancellation and account/lifetime loss discard late source choices. A stale-source response clears export confirmation without changing an uncertain delivery or its selected review.

`ConnectedFiles` composes these ports with the existing session lifetime, current account/client and document operation. Federal importing and publishing are available only for the Word operation. `proxyDocumentRequest` forwards four fixed public routes through the existing native session, deadline and bounded receiving owner. It does not authorize a document or trust a browser-supplied identity. `DocumentWorkflow` only carries and disposes the optional federal port.

## Author structural assessment

This is an implementation-author assessment; independent review remains held. The size scanner continues to report the exact findings. The review component's form transitions and conditional review/export controls form one presentation lifetime; splitting them by line count would distribute its confirmation and uncertain-write state. The separate importer owns only citation-page selection and pending-import presentation; it reports pending state to the same workbench lifetime. Receiving, persistence, compilation, authority and transport remain separate existing owners. `FederalWorkbenchAccess.deliver` replaces the former publish-only transaction and serves both writes: correlate intent, consult the shared journal, dispatch once, receive the exact publication and classify definite/uncertain outcomes. A synchronous busy reservation covers asynchronous fingerprinting. Separating these transitions would obscure their effect boundary. The enlarged host remains a connection composition owner; the optional port adds no second bootstrap or journal. The existing proxy and deadline callback retain one fixed forwarding responsibility, and the existing document adapter only acquires optional port custody. Exact fingerprints are recorded in the architecture registry without claiming independent approval.

## Evidence and limits

The installed public contracts 0.1.35 are used directly, without local aliases or copied DTOs. Synthetic import/review/publication fixtures are emitted by the mounted runtime application and actual compiler/artifact owners. Focused tests cover public receiving, native proxy admission, scoped history paging, stale context/source, saved ancestry, original-delivery recovery and shared pending writes. Five development Chrome checks cover confirmation, save/export/download, edit invalidation, import paging/remount recovery and stale-source recovery under StrictMode.

The source importer is implemented; no live official-source qualification or workflow activation is claimed. Native browser and Office/legal fidelity remain unqualified. No application build, deployment or provider call is part of this change. Existing unrelated architecture errors remain recorded separately from this change.
