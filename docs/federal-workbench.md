# Exact federal text review

The connected Word file workflow can open a retained TXT source envelope, prepare one literal replace, insert or delete amendment, save immutable review revisions and export operative, consolidated or redline TXT. Loading an existing multi-operation review supports reviewing and exporting it; editing it requires the full authoring surface, which is not implemented here. Publisher metadata is a retained claim, not proof of official provenance. Legal currency, enactment, numbering and substantive-law checks remain visible and unresolved.

## Ownership and failure handling

`FederalWorkbench` owns transient form, pagination, review confirmation and verified download presentation. Any amendment edit clears the prepared review and confirmation. Its effect lifetime cancels obsolete work, including development StrictMode replay. It neither compiles amendments nor grants authority.

`FederalWorkbenchAccess` uses the published `@capiro/meri-contracts/federal-workbench` receiver and existing document library. The canonical runtime compiler and Core current authority remain remote. Publishing uses the existing document attempt journal shared with ordinary document writes. A changed revision or output cannot replace an uncertain original delivery; remount recovery reconstructs the exact intent and reuses its original delivery ID. The journal stores hashes, identity and disposition, not review/source content. Saving a revision binds its old saved version and old reviewed digest separately from the new digest.

`ConnectedFiles` composes these ports with the existing session lifetime, current account/client and document operation. Federal publishing is available only for the Word operation. `proxyDocumentRequest` forwards three fixed public routes through the existing native session, deadline and bounded receiving owner. It does not authorize a document or trust a browser-supplied identity. `DocumentWorkflow` only carries and disposes the optional federal port.

## Author structural assessment

This is an implementation-author assessment; independent review remains held. The size scanner continues to report the exact findings. The new review component's form transitions and conditional review/export controls form one presentation lifetime; splitting them by line count would distribute its confirmation and uncertain-write state. Receiving, persistence, compilation, authority and transport remain separate existing owners. `FederalWorkbenchAccess.publish` is one ordered original-delivery transaction: correlate intent, consult the shared journal, dispatch once, receive the exact publication and classify definite/uncertain outcomes. Separating those transitions would obscure its effect boundary. The enlarged host remains a connection composition owner; the optional port adds no second bootstrap or journal. The existing proxy and deadline callback retain one fixed forwarding responsibility, and the existing document adapter only acquires optional port custody. Exact fingerprints are recorded in the architecture registry without claiming independent approval.

## Evidence and limits

The installed public contracts 0.1.33 are used directly, without local aliases or copied DTOs. Focused tests cover public receiving, native proxy admission, stale context, saved ancestry, original-delivery recovery and shared pending writes. This source does not activate the workflow, import official sources, qualify the actual native browser or prove Office/legal fidelity. No application build, deployment or provider call is part of this change. Existing unrelated architecture errors remain recorded separately from this change.
