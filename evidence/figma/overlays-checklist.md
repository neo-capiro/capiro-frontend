## Designs needed from Neo

- A disabled/unavailable Create with Meri chooser state, plus role denied, capacity limit, and billing disclosure states for the same dialog.
- The current global Quick log state before a client is chosen, and the transition from client selection to the inline command form. The Figma examples start with Anduril already selected.
- States for generic follow-up failures, missing assignee, uncertain receipts, and recovery; a combined commitment plus follow-up state; and approved forms for direction, counterparty, objective/strategy links, and a custom Planner task title. Direct commitment, occurrence time, and due date are wired to the existing Core activity endpoint and pass fixture-backed browser checks; live-auth behavior remains untested, while the richer fields still need backend/interaction contracts.
