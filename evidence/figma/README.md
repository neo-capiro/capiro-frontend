## Overview measurements

The 1440 × 1040 frame has a 64px global header, a 232px sidebar, and a 1208px main region. The scroll content has a 1080px grid inset 64px from the main's left edge. Its top row contains a 533 × 224 client card, a visible 351 × 104 combined government summary, and a 169 × 104 engagement health card. The older `Federal footprint` card (`1064:158952`) has `visible: false`. The district nexus card is 533 × 344, the engagement pulse is 533 × 412, objectives are 533 × 156, and deadline stress plus requests are 533 × 344. The timeline starts beneath the grid, at local y=924.

Both government tab frames show a visible modal at x=210, y=110, width=1020, height=820. Inside: header x=25/y=25/w=970/h=50; tabs y=91/h=36; scrollable details y=143/h=600; footer y=759/h=36. Identity panels have heights 190, 158, and 94px with 16px gaps. Federal panels have heights 166, 188, and 156px with 16px gaps.

## Data and state boundaries

Anduril, the financial totals, location counts, touch counts, and individual meeting rows are design preview examples. Live values must come from authorized sources. The integration frames `3034:53135` through `3034:53975` describe access denied, unmatched identity/recipient, partial coverage, and stale data. They explicitly hide protected cached fields when access is removed, keep unavailable values distinct from zero, and separate public program context from client-attributable awards. Location frames `3034:51112` through `3034:52846` cover loading, failed read, partial coverage, access removal, moved/deleted record, and evidence review.

The Agenda/Prep/Debrief frames use an `Anduril meetings` header with Sync calendar and Meeting Library actions. The Month/Week frames use a later `Anduril calendar` header and one large schedule card without those top actions. This is a Figma inconsistency; a unified current design state should be requested from Neo.

## Visible static assets

The overview's district map is a named `US dot map (Albers USA)` vector at local x=178, y=66, 339 × 258 inside the district card, with separate CA, AL, DC, MA, and OH marker layers. The combined government summary uses landmark and arrow-up-right SVGs. PR #92 already contains matching named candidate SVGs under `apps/web/public/design/411-47028-*` and `411-47066-*`; exact byte identity against the current Figma exports has not been established because the Figma asset host returned HTTP CONNECT 403 from the workspace shell. Use the current Figma node context and render to check any substitution.
