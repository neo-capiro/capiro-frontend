## Design or source gaps

- The shared header/sidebar owners need to compare the header collapse control, sidebar row/divider positions, and Prospects active state at `/portfolio?type=PROSPECT` with the Portfolio frame. Those files are owned by the parallel Meri visual task.
- Neo resolved the Agenda/Month/Week and Objective intake layout differences. The client Meetings header/actions are stable across views; the populated Objective profile layout is canonical for blank and filled states. [Resolved frame decisions](figma/decision-and-wiring.md).
- Core source now provides a registered client-attachment usage snapshot for the 10 GiB informational allowance. The successor renders available, over-allowance, and unavailable/failed-read states separately from the ACL-filtered file list. Live use awaits Core receiving and runtime routing. [Exact boundary](portfolio-core-contract-receiving.md).
- Core source now admits richer direct and durable-command Quick Log fields, including generic follow-up with a commitment and custom dates. The successor verifies details in direct receipts or canonical activity; Planner task title and Strategy step link still lack contracts, and Core/Planner do not share an atomic transaction. [Exact boundary](portfolio-core-contract-receiving.md).
- Figma preview values for engagement, urgency, deadline/request aggregates, weighted pipeline, win rate, and several Objective lifecycle measures do not have matching client-safe service fields. The build displays an unavailable state where needed.
- The live Figma asset host returned HTTP CONNECT 403 in this workspace. Existing named local vectors were checked visually against the rendered frames, but exact export-byte identity was not verified.

Mobile comparison is deferred by request. No deployment or live configuration change is part of this work.
