# Engagement ownership

`EngagementScreen` composes overview, meeting/library, outreach, report and commitment workflows. Each workflow has a cohesive public component and uses the core engagement controller's allowlisted operations. No external mail is sent by draft editing. Cross-client engagement plans and team ownership require an authoritative plan/ownership aggregate: no fabricated data or client-selected authority is introduced for these design surfaces.
