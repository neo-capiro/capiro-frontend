# Engagement ownership

`EngagementScreen` composes Outreach only. It retains ordinary draft and campaign session links, rich newsletter handoffs, and read-only Objective Outreach destinations. Draft editing does not send mail; delivery still requires its separate audited review and send intent.

Client meetings and the meeting library are presented in the client's Portfolio calendar. The separate Calendar module still uses its shared meeting components and Core meeting operations. Engagement report, plan, team, commitment, and meeting tabs are not part of this module.
