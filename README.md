# Capiro frontend

Independent product frontend for Meri and the future Portfolio, Modules and Settings areas. Created at the human owner's request on10October2026. Meri backend and runtime remain separately owned in [meri-greenfield](https://github.com/neo-capiro/meri-greenfield).

Read [the architecture and implementation outline](docs/ARCHITECTURE.md) and [implementation standards](docs/IMPLEMENTATION-STANDARDS.md) before changes. This repository initially contains ownership instructions; product implementation and verification follow on dedicated branches. No deployment or live service integration is established by repository creation.
